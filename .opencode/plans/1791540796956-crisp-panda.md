# Runes of the Fallen — Elden-Ring-Inspired Mobile Plan (Original Art Only)

> User asked for "exact to exact copy of Elden Ring" + pasted 11-section reference (menu, soundtrack, story, areas, underground, DLC, classes, systems, bosses, endings, atmosphere).
> **Cannot do an exact copy**: Elden Ring art, code, music, names, dialogue are copyrighted (FromSoftware/Bandai Namco). This plan builds **original analogues** that capture the feel/systems: same genres and loops, own names/meshes/music/text. No ripped models, textures, audio, or proper nouns (no Margit/Godrick/Rennala/Radahn/Malenia/Limgrave/Liurnia/Caelid etc.).

## 2. Recommended approach (phased, still single `index.html`)

Keep static single-file, Three.js CDN, touch-first, instanced meshes + pooled sprites, `LOWFX` perf path. All names/music/text original.

### Phase A — Menu + creation + saves (maps to user §1, §7)
- Upgrade `#title` (:106-116) to stack: Continue / New Journey / Load Journey / System. System: sound, Low/High FX (reuse `applyQuality()`), sensitivity slider, wipe save.
- Add `#create` overlay: 4 armor tints (reuse `makeKnight({armor,trim})`), 10 original classes (e.g. Wayfarer/Sellsword/Warden/Scholar/Friar/Corsair/Ashen/Stargazer/Outcast/Rootborn) as stat presets for `P.maxhp/dmg/maxst/maxfp` + starting art. Add `#load` 3 slots `localStorage rotf_save_<slot>` storing `{cls,tint,level,runes,gracesUnlocked,regionId,bossesDead,questFlags,playTime,drop}`.
- Files: `index.html` CSS `.overlay/.panel` + HTML overlays + boot `started` gate.

### Phase B — Multi-region map (maps to user §4, §5, §6, §11)
- Data-driven `REGIONS` reusing `WORLD_R/colliders/graces` system: Meadowreach (green starter), Weepmire (lake/blue fog + water plane), Ashen Scar (red sky/orange fog + embers), Frostfall (snow points), Deeproot Hollow (dark purple underground + glow shrooms), Gloam Spire (night final). `setRegion(id)` swaps `background/fog/hemi/sun/groundMat`, rebuilds `colliders` via existing `wall()`+arch, re-tints tree analogue, disposes/recreates `InstancedMesh` via `scatterInstanced()`.
- Gates: reuse arch (:256-261) as region portals → `centerMsg(REGION NAME)`. Expand `graces` to 8-10 `{x,z,region,name,unlocked}`; reuse beam/disc/light + `gracePts`; compass filters to current region. Keep fog-gate shimmer per boss arena.

### Phase C — Mount, travel, retrieval (maps to user §8)
- Stag-mount (Torrent analogue, primitive-built, no copy): `P.mounted`, speed 11, toggle `F` + `STAG` touch btn, blocks attack/heal, dash on double ROLL, auto-dismount in boss fog / on heavy hit.
- Fast travel in `#grace`: list `gracesUnlocked` → `setRegion+pos+respawnWorld()` (blocked while `bossActive`).
- Rune-drop retrieval: `die()` drops `drop={x,z,region,amount}` + gold sprite + compass mark; pickup r=2.5, overwrite on re-death. Fixes current keep-on-death (:475-479).

### Phase D — Summon + Arts + crafting/NPC (maps to user §8)
- Spirit Ash lite: `WOLF (C)` btn, 40FP, only near `rebirth Monument` obelisks (dist<25), 1 allied wolf (scaled `makeKnight` variant) with chase AI, 60s/boss-tied, upgrade via NPC.
- Ashes of War lite: `ART (Q)` btn, 3 swappable at Grace (Storm Edge ranged / Ember Slam AoE reusing `teleRing` / Mist Step dash) with FP costs, plus hidden enemy `poise` → 2s stagger.
- Crafting lite: instanced pickups (leaf/emberstone/frostcap/glowwort) → `Inv`, 4 recipes (Fire/Frost Pot, Bloom Meal, Stag Feed) in Grace submenu. 3 NPCs (Maren/Odo/Vey, 3 original lines each, `!` compass mark, `questFlags`: kill-4-hollows→+flask, summon upgrade, ending hint).

### Phase E — Bosses + endings + NG+ (maps to user §9, §10, §3)
- Generalize `boss` (:345-349) to `BOSSES[]` driving `#bossbar/#bossname/#bossfill`: keep Grove Warden, add Mire Warden (adds 2 hollows at 50%), Cinder Hound (fast + flame `teleRing` slams), Frost Elder (heavy + FP-drain gust), final Gloam Serpent (2-phase emissive swap, needs 2 seals). Reuse `awakenBoss/damageEnemy/updateEnemy` phase hooks.
- Endings (3 original, not 6 copied): `#win` choice Claim Throne / Quench Flame / Bloom Anew → different `winstats` + sky tint + `endingSeen`. `NG+`: `P.ng++`, enemies hp/dmg ×1.35, keep levels, reset bosses/graces.

### Phase F — Music + ambience (maps to user §2)
- New `MusicSys` (WebAudio generative, original progressions e.g. Dm-Bb-F-C pads, no transcribed tracks): pad/bass/timpani/choir-ish layers, scheduler 250ms lookahead, states menu/field/boss/deep with crossfades on `setRegion/awakenBoss/winGame`. Ambience: filtered-noise wind/water/drips + grace chimes. Respects `AudioSys.on`, `LOWFX` halves voices.

## 3. Out of scope (to stay shippable)
Multiplayer/co-op/PvP/messages, full open-world streaming (use per-region `WORLD_R` swap instead), full spellbook, complex status (rot/frost/sleep) beyond-lite, exact Elden Ring map/music/names.
